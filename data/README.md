# Dataset files

- `cardio_train_raw.csv`: 70,000 source records recovered from the supplied PDF; semicolon separator, age in days.
- `CARDIO_TRAIN_export.csv`: comma-separated export from the local SQL run, age in days.
- `cardio_train_clean.csv`: EDA data after IQR clipping, age in years. Do not use it as raw input.
- `extraction_audit.json`: source extraction and validation details.
